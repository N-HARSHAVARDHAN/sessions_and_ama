# AMA Answers

## 1. Adhikya Edammala — What is the difference between LangChain and LangGraph?

LangChain is used to build LLM applications using prebuilt tools and components.

LangGraph is used to build more complex AI agents where the workflow can have **state, loops, and multiple steps**.

**Simple difference:** LangChain provides the building blocks, while LangGraph helps manage complex agent workflows.

## 2. Boorle Sowmya Sri Lakshmi — What is the use of MIME type?

A MIME type tells the browser or application **what type of data or file is being sent**.

Examples:

* `text/html` → HTML
* `application/json` → JSON
* `image/png` → PNG image

It helps the browser or application understand how to handle the data.

## 3. Md Musharaf — What is the use of evals?

Evals are used to **test and measure the performance of an AI model or AI application**.

They help check whether the AI gives:

* Correct answers
* Good quality responses
* Expected behavior

**Simple example:** Giving the AI multiple test questions and checking how well it answers them.

## 4. Rongala Vasu — What is transport?

Transport refers to the process of **sending data from one application or device to another over a network**.

The transport layer helps manage how the data is delivered.

Examples of transport protocols are:

* **TCP** → Reliable data delivery
* **UDP** → Faster but less reliable delivery

## 5. Vikas Mehta — What is jailbreaking?

Jailbreaking is an attempt to **bypass an AI model's rules or safety restrictions using special prompts**.

For example, a user may try to make an AI ignore its original instructions and do something it is not supposed to do.
