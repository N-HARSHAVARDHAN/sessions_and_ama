# ama_answers:
*  **Adhikya Edammala – useMemo:** `useMemo` memoizes a calculated value so it is not unnecessarily recalculated on every render.
* **Allanki VV Manikanta Sai – useState:** `useState` is a Hook used to create and manage state in a React component.
* **Boorle Sowmya Sri Lakshmi – ANTD components:** Common Ant Design components include `Button`, `Input`, `Form`, `Table`, `Modal`, `Card`, and `Select`.
* **Md Musharaf – Context API:** Context API is used to share data across components without passing props through every intermediate component.
* **Rongala Vasu – State vs Props:** State is internal and changeable data owned by a component, while props are read-only data passed from a parent to a child.
* **Vikas Mehta – Unnecessary props drilling:** We can avoid props drilling by using **Context API** or a state-management library.
