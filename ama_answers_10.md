# AMA Session Questions and Answers

### Adhikya Edammala: Is React a library or a framework?

React is a **JavaScript library** used to build user interfaces.

---

### Allanki VV Manikanta Sai: Difference between DOM and Virtual DOM

| DOM                | Virtual DOM                 |
| ------------------ | --------------------------- |
| Real DOM           | Lightweight copy of the DOM |
| Slower updates     | Faster updates              |
| Updates entire DOM | Updates only changed parts  |

---

### Arpit Yadav: Difference between a Library and a Framework

| Library              | Framework                   |
| -------------------- | --------------------------- |
| You control the flow | Framework controls the flow |
| Flexible             | Provides structure          |
| Example: React       | Example: Angular            |

---



### Md Musharaf: What is JSX?

JSX (JavaScript XML) is a syntax that lets you write **HTML-like code inside JavaScript**.

---

### Naman Sharma: What is State?

State is data managed by a component. When state changes, React re-renders the component.

---

### Parlapalli Sulochana: What is the return type of a React component?

A React component returns **JSX (React elements)**.

---

### Rongala Vasu: How do you pass data to components?

Data is passed from a **parent component to a child component using props**.

---


### Vikas Mehta: What is Lifting State Up in React?

Lifting state up means **moving state to the nearest common parent** so multiple components can share the same data.
