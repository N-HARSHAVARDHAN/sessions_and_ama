# AMA Questions & Answers

* **Boorle Sowmya Sri Lakshmi – What is the use of `useState`?**
  **`useState` is a React Hook used to store and update data in a component, automatically re-rendering the UI when the data changes.**

* **Md Musharaf – How does the browser understand JSX?**
  **The browser doesn't understand JSX directly; tools like Babel convert JSX into JavaScript (`React.createElement()` or the new JSX runtime) before it runs.**

* **Rongala Vasu – Tell me asynchronous JavaScript examples.**
  **Examples:** `setTimeout()`, `fetch()`, Promises, `async/await`, `setInterval()`, WebSocket events, FileReader API.

* **Vikas Mehta – When should we use indexing and when should we not use indexing?**
  **Use indexing for columns frequently used in `WHERE`, `JOIN`, `ORDER BY`, or `GROUP BY`; avoid indexing columns that change frequently or have very few unique values.**
