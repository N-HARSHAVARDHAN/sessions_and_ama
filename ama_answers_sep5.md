# ama answers:

  **Adhikya Edammala – Difference between LangChain and LangGraph?**
  **LangChain** is used to build LLM applications and chains, while **LangGraph** is used to build more complex, stateful AI agents with workflows, loops, and multiple steps.

 **Boorle Sowmya Sri Lakshmi – What is the use of a reducer in Redux?**
  A **reducer** is a function that takes the current state and an action, then returns the updated state.

 **Md Musharaf – Why do we pass `key` in React when using `map()`?**
  A **key** uniquely identifies each list item, helping React efficiently detect which items were added, removed, or updated.

 **Rongala Vasu – How to optimize an N+1 query?**
  We can optimize an **N+1 query** by fetching related data in a single query using techniques like **JOIN, eager loading, or prefetching**, instead of making separate queries for each item.

 **Vikas Mehta – What is RAG?**
  **RAG (Retrieval-Augmented Generation)** is an AI technique where relevant information is first retrieved from a knowledge source, and then given to the LLM to generate a more accurate answer.
